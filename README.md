# Клон сайта RODER (roder.ru)

## Структура проекта

```
Родер Сайт/
├── index.html          — Главная страница
├── css/
│   └── style.css       — Все стили сайта
├── js/
│   └── app.js          — JavaScript (слайдер, меню, модалка)
├── images/
│   ├── favicon.ico     — Иконка сайта
│   ├── index__roder.jpg — Фон секции "О компании"
│   └── svg/            — SVG логотипы и иконки
├── fonts/              — Шрифты (нужно скачать Manrope и Inter)
└── README.md           — Этот файл
```

## Как запустить

1. Просто откройте `index.html` в браузере
2. Или запустите локальный сервер:
   ```bash
   cd "Родер Сайт"
   python3 -m http.server 8000
   ```
   Затем откройте http://localhost:8000

## Что можно редактировать

- **Тексты** — прямо в `index.html`
- **Стили** — в `css/style.css`
- **Логика** — в `js/app.js`
- **Изображения баннеров** — замените URL в атрибутах `style="background-image: url(...)"` в index.html
- **Контакты** — телефон, email в шапке и подвале

## Шрифты

Сайт использует шрифт **Manrope**. Для полной работы скачайте его:
- https://fonts.google.com/specimen/Manrope
- Положите файлы .ttf в папку `fonts/`

Или подключите через Google Fonts, добавив в `<head>`:
```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

## Деплой

Проект полностью статический. Можно выложить на:
- **Netlify** — перетащите папку на netlify.com/drop
- **Vercel** — `vercel deploy`
- **GitHub Pages** — загрузите в репозиторий
- **Любой хостинг** — просто загрузите файлы по FTP

## Примечания

- Изображения баннеров пока загружаются с roder.ru. Для полной автономности скачайте их локально и замените пути.
- Это статическая копия главной страницы. Внутренние страницы (каталог, проекты) нужно клонировать отдельно при необходимости.
